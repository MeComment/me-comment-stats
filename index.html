Me Comment Stats

A personal, single-user dashboard for managing the owner's own TikTok channel — built and used exclusively by the owner of @me.comment1.

Review & publish original videos

Self-created videos are reviewed on a local dashboard, given a caption, and posted to the owner's own TikTok profile via the Content Posting API.

Private analytics

Daily view, like, comment, share and follower statistics for the owner's own videos, fetched via the Display API and stored only on the owner's computer.

Single user, by design

No third-party users, no data collection from anyone else, no engagement automation.

One channel, one owner,
one quiet dashboard.

Me Comment Stats is a personal, single-user tool — built and used exclusively by the owner of the TikTok account @me.comment1 to run their own channel.

Review & publish
Self-created videos are reviewed on a local dashboard, given a caption, and posted to the owner's own profile through the TikTok Content Posting API.
Private analytics
Daily views, likes, comments, shares and follower counts for the owner's own videos, fetched via the Display API and stored only on the owner's computer.
Single user, by design
No third-party users, no data collected from anyone else, no engagement automation of any kind.
